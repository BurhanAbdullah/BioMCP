Specialized scientific capabilities, clearly labeled.

BioMCP does not hide integration maturity. Each server is represented by its actual lifecycle and installation boundary.

Experimental · installable

LLM Bridge

Connect an OpenAI-compatible model endpoint to MCP workflows.

biomcp-llm

Validated · external

BioNuclei

BioMCP can expose supported BioNuclei operations without copying its scientific implementation into the platform. The external server remains responsible for its scientific computation and validation.

The registry is the source of truth for whether an integration is bundled, external, installable, or planned.

Lifecycle

What each status means.

StatusMeaning
PlannedCatalogued, but not installable.
ExperimentalRunnable integration under active validation.
ValidatedExecutable integration supported by tests and documented evidence.
DeprecatedRetained for compatibility or history, but no longer an active integration path.
Registry-first rule: do not infer availability from a page card. Use biomcp list and the machine-readable registry when making installation decisions.
