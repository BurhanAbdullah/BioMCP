Client connectivity

Configure the MCP host you already use.

The BioMCP installer generates configuration for supported hosts instead of asking users to hand-build every server entry.

Supported writer

Claude Desktop

Generate JSON MCP server entries from the BioMCP installer.

biomcp install --servers bioimage,llm --clients claude-desktop
Supported writer

Codex

Generate MCP server entries in the Codex TOML configuration.

biomcp install --servers bioimage,llm --clients codex
Generic output

Generic MCP hosts

Print or write standard mcpServers JSON for hosts without a promoted host-specific writer.

biomcp install --servers bioimage,llm --clients generic
Not a promoted target

Claude Code

Claude Code is not currently a host-specific installer target. Until a supported configuration contract is implemented and tested, configure its MCP mechanism directly.

External

BioNuclei

BioNuclei is exposed as an external server. It is not installed or implemented by BioMCP; configure its own server command in your MCP host.

Generated configuration

Keep the boundary visible.

{ "mcpServers": { "biomcp_bioimage": { "command": "biomcp-bioimage", "args": [] } } }
Preview first: use --dry-run when you want to inspect client configuration before writing it.
