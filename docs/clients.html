Clients

Connect the AI host you already use.

BioMCP generates or prints MCP server configuration instead of forcing users to hand-write command entries.

Claude Desktop

Configure JSON MCP server entries from the BioMCP installer.

biomcp install --servers bioimage,llm --clients claude-desktop

Claude Code

Use registered BioMCP server commands from your coding/agent environment.

biomcp install --servers bioimage,llm --clients claude-code

Codex / compatible hosts

Use the generic MCP configuration when a host-specific writer is not yet promoted.

biomcp install --servers bioimage,llm --clients generic

External BioNuclei adapter

BioNuclei is exposed as a validated external server, not installed or implemented by BioMCP. Obtain its bionuclei-mcp server through the BioNuclei release channel and configure that command directly in your MCP host.
