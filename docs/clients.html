Clients

Connect the AI host you already use.

BioMCP generates or prints MCP server configuration instead of forcing users to hand-write command entries.

Claude Desktop

Configure JSON MCP server entries from the BioMCP installer.

biomcp install --servers bionuclei --clients claude-desktop

Claude Code

Use the same registered server command from your coding/agent environment.

biomcp install --servers bionuclei --clients claude-code

Codex / compatible hosts

Use the generic MCP configuration when a host-specific writer is not yet promoted.

biomcp install --servers bionuclei --clients generic

The generated entry

{
"mcpServers": {
"biomcp_bionuclei": {
"command": "bionuclei-mcp",
"args": []
}
}
}
