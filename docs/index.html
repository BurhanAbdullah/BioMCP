The platform

One layer for scientific interoperability.

BioMCP makes discovery, installation, configuration, and agent connectivity predictable while keeping scientific computation independent.

01. Discover

Registry first

Machine readable metadata makes lifecycle state, installation options, transport, and capabilities explicit.

02. Connect

Protocol native

03. Compose

Modular by design

Scientific servers remain independently executable, testable, replaceable, and maintainable.

BioMCP

Interoperability layer

MCP schemas, discovery, registry metadata, server configuration, client connectivity, and transport belong here.

Design principle. BioMCP routes and exposes scientific capabilities. It does not silently replace the scientific software that produces them.
