The platform

One layer for interoperability.

Keep scientific computation independent while making discovery, installation, and agent connectivity predictable.

01 · Discover

Registry-first

Machine-readable metadata makes lifecycle state, installability, transport, and capabilities explicit.

02 · Connect

Protocol-native

Use MCP-compatible servers and client configuration rather than bespoke agent integrations.

03 · Compose

Modular by design

Scientific servers remain independently executable, testable, replaceable, and maintainable.

Scientific boundary

AI orchestrates. Science executes.

Underlying software

Scientific authority

Computation, measurements, validation, evaluation, artifacts, and scientific provenance remain with the domain implementation.

BioMCP

Interoperability layer

MCP schemas, discovery, registry metadata, server configuration, client connectivity, and transport belong here.

Design principle. BioMCP routes and exposes scientific capabilities; it does not silently replace the scientific software that produces them.
Quick start

Start with three commands.

Install the platform, inspect what is available, then configure only the servers you need.

pip install biomcp biomcp list biomcp install --servers bioimage --clients generic biomcp doctor
