Discover

Install

Use one CLI to configure servers for your MCP client instead of hand-editing every configuration file.

Compose

Let an LLM move between specialized scientific servers while each server keeps its own tool contract.

Quick start

From zero to MCP.

Install the package, inspect the registry, run diagnostics, then configure a client.

pip install biomcp

biomcp list
biomcp doctor
biomcp install --servers bionuclei
