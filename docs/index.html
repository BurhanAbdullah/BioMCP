Open scientific software interoperability

Connect scientific software through MCP.

BioMCP is an open-source scientific interoperability platform built around the Model Context Protocol (MCP). Connect scientific applications, command-line tools, model runtimes, and external MCP services through one consistent interface.

How it works

AI requests. Scientific software executes.

BioMCP focuses on interoperability rather than reimplementing scientific software. The scientific application remains responsible for its algorithms and scientific computation; BioMCP provides the integration, execution boundary, protocol interface, configuration, and result transport.

Current Integrations

Registered capabilities with explicit lifecycle state.

BioMCP uses conservative lifecycle states. The presence of a planned software project in the roadmap does not mean that an adapter has already been implemented.

Quick start

Start with the platform package.

Use the CLI to discover registered servers, choose the integrations you need, preview configuration, and check the local environment.

Install

Install the package

pip install biomcp
Check

Check the installation

biomcp doctor
Discover

See available integrations

biomcp list
Launch

Launch an MCP server

biomcp run bioimage
