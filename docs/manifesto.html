Manifesto

Less MCP friction. More scientific work.

BioMCP exists to make scientific software accessible to AI without hiding how the work was done.

Open

Prefer open scientific software and public interfaces.

Composable

Let specialized servers work together without collapsing them into one opaque agent.

Auditable

Keep tool identity, outputs, validation state and provenance visible.

What BioMCP is not

It is not a general-purpose autonomous scientist, not a benchmark generator, and not a replacement for the scientific programs it connects.

Scientific interoperability by design.
