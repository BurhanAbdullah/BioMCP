Contributing

Build the scientific MCP layer.

BioMCP is intended to grow through small, testable integrations. A new server should be useful to an LLM and trustworthy to a scientist.

1. Server

Provide a real executable MCP server with explicit tools, inputs, outputs, and transport.

2. Metadata

Add a registry entry with category, status, installability, command, transport, and scientific boundary.

3. Evidence

Add regression tests, installation/usage documentation, and reproducible validation before claiming “validated”.

Promotion rule

planned → experimental → validated → deprecated

Do not mark an integration validated because a server starts. Validation should cover the tool contract, representative outputs, failure behavior, and provenance boundary.
