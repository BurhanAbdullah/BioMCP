Examples

From a scientific question to a tool call.

BioMCP gives an AI host a structured route to specialist scientific capabilities while keeping the underlying computation explicit.

Workflow 01 · Bioimage

Inspect and quantify an image

A host can request image analysis and route the request to the appropriate scientific server.

User → Analyze this fluorescence image and count nuclei. Agent → BioMCP → BioNuclei inspect_image predict_image load_result_summary
Workflow 02 · Evidence

Keep the result traceable

When the underlying server provides them, structured results can carry measurements, output artifacts, and provenance.

tool result ├── summary ├── measurements ├── output files └── provenance
Design pattern

Separate orchestration from measurement.

Agent

Request and orchestrate

Interpret the user's request, select an available capability, and provide the tool arguments.

→
Scientific server

Execute and validate

Perform the domain computation and return the authoritative scientific result.

Evidence boundary: BioMCP does not manufacture evaluation metrics for arbitrary user data. Scientific benchmark claims remain tied to defined protocols and evidence.
