Installation

Install once. Connect your AI.

BioMCP is one Python package. Start with the platform, then add the scientific server families you actually use.

1. Install

pip install biomcp

2. Discover

biomcp list

3. Diagnose

biomcp doctor

4. Configure

biomcp install --servers bioimage,imagej,llm --clients claude-desktop

Add what you need

BioImage

pip install 'biomcp[bioimage]'

Image inspection and quantitative primitives.

ImageJ / Fiji

pip install 'biomcp[imagej]'

Requires a local ImageJ/Fiji installation configured with BIOMCP_IMAGEJ_EXECUTABLE.

LLM

pip install biomcp

Configure BIOMCP_LLM_BASE_URL, BIOMCP_LLM_API_KEY, and BIOMCP_LLM_MODEL.

Install only real integrations

The registry distinguishes installable, experimental, planned, and external integrations. For example, BioNuclei is an external validated server and is not silently bundled into the BioMCP wheel.
