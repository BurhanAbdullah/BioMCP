Installation

Install once. Configure deliberately.

Use the CLI to discover registered servers, choose the integrations you need, preview configuration, and check the local environment.

01. Install

Base package

pip install biomcp

Start with the platform package and add optional server dependencies when required.

02. Inspect

Read the registry

biomcp list

Review availability and lifecycle information before configuring a host.

03. Configure

Choose a host

biomcp install --servers bioimage,llm --clients generic

Use --dry-run to preview configuration without writing it.

04. Diagnose

Check the environment

biomcp doctor

Run diagnostics before opening an MCP client session.
