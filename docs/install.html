Installation

Install once. Connect your AI.

BioMCP is distributed as one Python package. Start with the core registry, then configure the scientific servers you actually need.

1. Install

pip install biomcp

2. Discover

biomcp list

3. Diagnose

biomcp doctor

4. Configure

biomcp install --servers bionuclei --clients generic

What installation does

Registry

Reads the machine-readable BioMCP server catalog.

Client config

Adds registered MCP servers to a local client configuration without overwriting unrelated entries.

Validation

Separates installable servers from planned integrations so users are never given a fake adapter.

Scientific rule: a server is marked installable only when its runtime and tool contract are actually present. Planned integrations are visible but cannot be launched.
